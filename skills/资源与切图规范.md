# 资源与切图规范

> 本文档定义了项目中图片资源的切图、存放、命名及在代码中引用的强制标准。

## 1. 资源存放位置 (Mandatory)

**核心规则：图片资源必须放在当前页面所属模块的 `composeResources/drawable/` 目录下！**

| 页面所在模块 | 图片放置路径 | 命名前缀 |
| :--- | :--- | :--- |
| `shared_project` | `shared_project/src/commonMain/composeResources/drawable/` | `project_` |
| `shared_common` | `shared_common/src/commonMain/composeResources/drawable/` | `common_` |
| `shared_base` | `shared_base/src/commonMain/composeResources/drawable/` | `base_` |

⚠️ **注意**：即使页面中引用了 `shared_common` 的组件，图片也必须放在页面所在的模块。不要跨模块放图片。

## 2. 切图规范

### 2.1 尺寸与格式
- **尺寸**：只切 **drawable-xxhdpi** 尺寸（对应 Android 375ppi）。
- **格式**：**强制优先使用 WebP 格式！** 除非有极特殊需求，否则禁止使用 PNG。

### 2.2 命名规则
- 仅支持小写字母和下划线 `_`。
- 必须带模块前缀（`project_` / `common_` / `base_`）。
- 示例：`project_ic_user_avatar.webp`

## 3. 代码引用规范 (重要：解决爆红)

使用图片资源时，**必须同时添加两行 import**，缺一不可！

### 3.1 正确写法示例

假设你在 `shared_project` 模块使用 `project_ic_phone.webp`：

**文件顶部 import 区：**
```kotlin
import com.basic.project.R_com_basic_project  // 1. R 类，提供 drawable 访问
import com.basic.project.project_ic_phone     // 2. 资源名，解决编译器识别问题
```

**使用处：**
```kotlin
Image(
    painter = painterResource(R_com_basic_project.drawable.project_ic_phone),
    contentDescription = null,
    modifier = Modifier.size(24.dp),
    contentScale = ContentScale.FillWidth
)
```

### 3.2 各模块对应关系

| 模块 | namespace | R 类名 |
| :--- | :--- | :--- |
| `shared_project` | `com.basic.project` | `R_com_basic_project` |
| `shared_common` | `com.basic.common` | `R_com_basic_common` |
| `shared_base` | `com.basic.base` | `R_com_basic_base` |

## 4. 故障排除

如果引用图片时 IDE 爆红：
1. **执行生成任务**：在终端运行 `./gradlew generateComposeResClass`。
2. **检查 Import**：确认上述“两行 import”是否都已手动添加。
3. **不要盲目重试**：不要通过修改文件名或重复切图来解决爆红问题。
